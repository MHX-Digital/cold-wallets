# Support

This repository provides experimental source code and audit evidence. It does
not provide production wallet support, custody, recovery services, investment
advice, or a guarantee against loss.

Use GitHub Issues for reproducible non-security bugs and feature requests. Use
GitHub Private Vulnerability Reporting for security reports as described in
[SECURITY.md](SECURITY.md). Do not post wallet data, addresses linked to your
identity, transactions, credentials, keys, or seeds.

Maintainers may close requests involving real funds, unsupported forks,
third-party deployments, mainnet testing, or attempts to bypass the documented
safety controls. There is no guaranteed response time.
