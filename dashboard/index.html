Safe workflow

  1. Prepare a proposal online.
  2. Review network, destination, value, maximum fee, proposal hash, and risk.
  3. Export the versioned artifact.
  4. Sign offline on a separate host after independent review.
  5. Import the signed artifact.
  6. Validate signature and proposal binding.
  7. Transmit only after the controlled-validation gate is enabled.
  8. Track the persistent broadcast state.

Current next step: use the coordinator CLI/service contracts. The browser intentionally has no signing or live-transmit control.
